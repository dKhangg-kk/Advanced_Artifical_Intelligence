# HOWTO Cover the Course Prereqisits

Studying the material requires:

* Python programming skills
* practical knowledge of how to implement data structures (Big-O notation, search trees)
* Knowledge of probability theory and combinatorics basics

You should already have good practical knowledge of these topics from courses on programming, data structures and algorithms,
discrete math, and statistics. If you feel not well prepared in one of these areas then here are some pointers on how to
prepare.

__Note:__ Please contact me if you find a link that does not work.

## Python Skills

* W3School's [Python Tutorial](https://www.w3schools.com/python/default.asp): go through sections as needed
* W3School's [NumPy Tutorial](https://www.w3schools.com/python/numpy/default.asp): go through "Basic"
* W3School's [Pandas Tutorial](https://www.w3schools.com/python/pandas/default.asp): go through "Basic"
* Dataquest's [Intro to Jupyter Notebook](https://www.dataquest.io/blog/jupyter-notebook-tutorial/)

## Data Strucutres and Algorithms

* [Data Structures and Algorithms in Python - Full Course for Beginners](https://www.youtube.com/watch?v=pkYVOmU3MgA&list=RDCMUC8butISFwT-Wl7EV0hUK0BQ): Choose what you are lacking.
