## Quy tac chot truoc khi nop

1. Moi thanh vien bo sung so gio thuc te, khong dien theo uoc luong.
2. Moi dong cong viec phai co commit, PR, issue hoac file ket qua tuong ung.
3. Tong ty le dong gop phai bang 100% va phan anh ca code, tai lieu, thi nghiem,
   thuyet trinh.
4. Khong ghi nhan training, benchmark hoac checkpoint neu khong co log/chung
   cu trong repository.
